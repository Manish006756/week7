# To-Do List Program

## Overview
This program stores user-entered tasks in a list and displays them back in an organized format.

## Functional Requirements
- Accept task inputs
- Store tasks in data structure
- Display all tasks

## Software Design Principles Applied

### 1. Data Abstraction
Tasks are stored in a Python list, which abstracts multiple values into one manageable structure.

### 2. Scalability
The program currently stores three tasks, but can easily be expanded to unlimited tasks using loops or menus.

### 3. Maintainability
The logic is separated into input collection and display stages for easier updates.

### 4. Reusability
The list-handling logic can be reused in shopping lists, reminders, booking systems, and note apps.

### 5. User Experience
The output is simple, clean, and easy to read.

## Possible Improvements
- Add delete task option
- Save tasks to file
- Mark tasks as completed
- Use menu-driven system
